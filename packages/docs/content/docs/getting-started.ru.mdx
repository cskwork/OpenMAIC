OpenMAIC — это приложение Next.js, которое можно запустить на своей машине. Вам нужны Node.js, pnpm и как минимум один API key для LLM.

## Требования

- **Node.js** 20.9.0 или новее
- **pnpm** 10.28.0 (при необходимости установите через `npm install -g pnpm@10.28.0`)
- Как минимум один LLM provider. Облачным provider обычно нужен API key; локальным Ollama и Lemonade ключ не нужен.

## Установка

Клонируйте репозиторий и установите зависимости:

```bash
git clone https://github.com/THU-MAIC/OpenMAIC.git
cd OpenMAIC
pnpm install
```

На этапе установки также собираются два workspace-пакета (`mathml2omml` и `pptxgenjs`). При первом запуске это занимает около минуты.

## Настройка

Скопируйте пример env-файла и заполните как минимум одного LLM provider:

```bash
cp .env.example .env.local
```

Откройте `.env.local` и укажите провайдеры, для которых у вас есть key. Например:

```bash title=".env.local"
OPENAI_API_KEY=sk-...
# или
ANTHROPIC_API_KEY=sk-ant-...
# или локальный Ollama (key не нужен)
OLLAMA_BASE_URL=http://localhost:11434/v1
```

Настройки provider, генерации изображений и видео, TTS, ASR, разбора документов, web search, контроля доступа и feature flags см. в разделе [Конфигурация](./configuration.mdx).

## Запуск

Запустите dev server:

```bash
pnpm dev
```

Откройте [http://localhost:3000](http://localhost:3000), введите тему или загрузите учебные материалы и нажмите Generate. AI teacher соберёт полноценный classroom из нескольких сцен. Форматы зависят от выбранного parser и обычно включают PDF, Office-документы, Markdown/обычный текст, изображения и некоторые аудио/видео.

## Production build

```bash
pnpm build
pnpm start
```

Также можно развернуть OpenMAIC на Vercel, Docker или собственном сервере — см. [Развертывание](./deployment.mdx).
